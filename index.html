4 Departmental Business Logic & Marital Validation Rules

Core Logic

Official specifications defined by Pooja Ma'am for spousal mappings in New Registration and Add Member workflows:

1. Marital Status – Married

  • Gender: Only opposite gender is allowed.
  • Age Validation: Male ≥ 21 years, Female ≥ 18 years.
  • Allowed Spouse Status: Unmarried, Divorced, Widow.
  • Certificate: Marriage certificate number & document mandatory.

2. Marital Status – Divorced

  • Gender: Only opposite gender is allowed.
  • Age Validation: Male ≥ 21 years, Female ≥ 18 years.
  • Allowed Spouse Status: Unmarried, Married, Divorced, Widow.
  • Spouse Entry: Prior spouse details not mandated in active family.

3. Marital Status – Widower

  • Gender: Only opposite gender is allowed.
  • Spouse Status: Spouse must be marked as deceased.
  • Allowed Spouse Status: Unmarried, Married, Divorced, Widow.
  • Database Validation: If selected spouse marital status is Married, the Spouse ID must remain BLANK in the database.

The Complete SCD 2.0 QA Framework: 7 Testing Dimensions

Testing a multi-tier government social welfare platform requires deep, white-box and grey-box engineering coverage across UI, API, database, and security boundaries.

1

UI / UX & Mobile Responsiveness

Cross-viewport, touch gestures, layout shifts
  • Touch Event Handlers: Eye icon on Aadhaar unmask lacks touchstart / touchend, failing on mobile viewports (BUG-03).
  • Alignment Integrity: Staggered alignment of "Read More" buttons on service cards across Hindi and English (BUG-04).
  • Silent Validation Freezes: "Add Member" button becomes unresponsive when forms are silently invalid without showing red feedback text (BUG-12).
2

Content & Hindi Localization (i18n)

Transliteration, Unicode parsing, header text leaks
  • Transliteration Duplication: Auto-fill copies First Name Hindi transliteration into Last Name, producing "अलीज़ा अलीज़ा" (BUG-07).
  • DOM Text Leakage: Section header text leaked into Father/Mother Hindi input fields (BUG-10).
  • Placeholder Consistency: Mixing "Select Local Body" vs "Please Select Zone" (BUG-09) and double commas in address concatenation (BUG-08).
3

Logical & Business Rules

Eligibility, age gates, marital constraints
  • Infant Without Aadhaar: Validating members <1 year old using official Birth Certificate numbers.
  • HoF Age Gating: Enforcing HoF must be at least 18 years old.
  • Spousal Linkage Permutations: Testing 81 scenarios of Married, Unmarried, Divorced, Widowed, and Abandoned pairings.
4

API Contract & Decrypted Payloads

AES encryption, serialization, status codes
  • Frontend Document Drop: Frontend completely omitted infant Birth Certificate and spouse Marriage Certificate from DocumentRequestModels (BUG-02).
  • Unhandled 500 Responses: InsertRequest throwing HTTP 500 with unhandled code MDL_00_000 (BUG-01).
  • Missing Resource Key: Backend throwing Message resource not found in ErrorMessages_en.resx.
5

Database Transactions & Audit Trails

Stored procedures, rollbacks, ADV logging
  • Hard Transaction Rollbacks: Confirmed 0 rows inserted in TBL_COMMON_REQUEST_MASTER on failed submissions.
  • Aadhaar eKYC Audit: Verifying TBL_AADHAAR_INTEGRATION_LOGS stores IS_SUCCESS=1 and masked UIDs.
  • SMS Audit Exposure: Confirming plain-text OTPs logged directly in TBL_SMS_AUDIT.SMS_OTP.
6

Security & Input Sanitization

Injection boundaries, buffer lengths, sanitization
  • Zero Backend Validation: .NET API accepted and committed 250+ characters of English bug report prose into Hindi name fields without rejection (BUG-13).
  • Regex Punctuation Freezes: Typing leading dots (. . .) in names causes silent front-end blocking without feedback.
7

Cross-Module & Reverse-Sync Engine

Common request routing, role mapping, legacy sync
  • Request Routing: Dynamic assignment of ACTION_ID and LEVEL_ID (GP vs Ward) in TBL_COMMON_REQUEST_MASTER.
  • Reverse Sync Outbox: Validating rows written to TBL_REVERSE_SYNC_QUEUE for synchronization back to legacy Samagra 1.0.
Essential Testing Dimensions to Cover Next (What Might Be Forgotten)

Concurrency & Race Conditions

Rapid double-clicking "Save & Submit" or "Add Member". Does it create duplicate rows or crash on primary key conflict?

Session Expiry on Preview

Waiting >15 minutes on Step 3 Preview before clicking submit. Does the token refresh gracefully or discard all entered members?

MIME-Type & Payload Boundary

Uploading non-PDF files renamed with a .pdf extension, or files >300 KB. Does the server validate file magic bytes?

Network Latency & Slow 3G

Simulating rural broadband latency (Slow 3G) in DevTools to check if loaders remain active or allow corrupted partial submissions.

Cross-Browser Rendering

Testing on iOS Safari (WebKit) and Firefox where flexbox wraps, date pickers, and Hindi Unicode ligatures often break differently from Chrome.

Aadhaar ADV Token Expiry

Replaying an old REF_KEY after 24 hours to ensure Aadhaar Data Vault tokens cannot be replayed or hijacked.
